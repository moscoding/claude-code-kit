# Апдейт для клиента, 15 мая

## Готово
- Дизайн первого экрана утверждён: макет согласован, правки по мобильной версии внесены, шрифты и цвета совпадают с гайдом бренда (inputs/tasks.csv:2).
- Аналитика событий настроена: заявки, клики по кнопке записи и прокрутка до блока тарифов собираются в одном отчёте, данные обновляются раз в сутки (inputs/tasks.csv:7).
- Страница статуса запуска пересобирается скриптом после каждого обновления задач, так что на ней всегда видна текущая картина по блокерам и просрочкам (method.md:3).

## В работе
- Финальный текст первого экрана: черновик готов, идёт сверка каждого утверждения с источниками (inputs/tasks.csv:3).
- Юридические формулировки на проверке (inputs/tasks.csv:4).
