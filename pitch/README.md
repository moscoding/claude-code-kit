# pitch

Модуль «Сайты: портфолио, питч, лендинг», практика «Веб-питч для заказчика».

## Что внутри

- `brief.md` — бриф заказчика: Orbidesk, B2B-сервис поддержки клиентов с ботом. Зачем питч, кто будет на
  встрече, какие слайды нужны, правила по цифрам и логотипам.
- `data/metrics.csv` — помесячные данные похожего клиента Orbidesk за апрель — сентябрь 2026 года: обращения,
  диалоги бота, закрытые ботом обращения, время первого ответа, оценка поддержки. Колонки описаны в брифе.
- `data/pricing.csv` — тарифы Orbidesk.
- `screens/` — скриншоты интерфейса (заглушки): `inbox.png`, `bot-flow.png`, `analytics.png`,
  `knowledge-base.png` и новый инбокс `inbox-v2.png` для правок заказчика.
- `logo.svg` — логотип Orbidesk.
- `feedback.md` — правки фаундера к первой версии питча. Открывайте, когда практика попросит.
- `checks/check_pitch.py` — автопроверка питча.

Заказчик, его клиенты и цифры придуманы для курса. `sales@example.com` — заглушка.

## Что копировать

Питч живёт в отдельном репозитории рядом с `launch-kit`, например `orbidesk-pitch`. Бриф и данные Claude читает
прямо из `../claude-code-kit/pitch/`, а в репозиторий питча кладёт только то, что нужно странице: логотип и
подготовленные скриншоты.

## Проверка

Из корня репозитория питча:

```bash
python3 ../claude-code-kit/pitch/checks/check_pitch.py
```

Семь критериев: питч — одна страница `index.html`, каждый слайд — `<section>` с заголовком (не меньше шести);
слайды листаются клавишами; стили печати `@media print` с разрывом страницы после слайда; картинки до 500 КБ;
`alt` у картинок; нет «Lorem ipsum» и «TODO»; `title`, `og:title` и `og:image`. Проверка только читает файлы.

Что слайд помещается на страницу PDF целиком, скрипт не видит: это проверяют глазами в «Сохранить как PDF».
