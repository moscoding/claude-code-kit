# reels

Модуль «Ролики для соцсетей», практика «Ролик из отчёта по каналам».

## Что внутри

- `inputs/campaigns.csv` и `inputs/channel-summary.csv` — запасные копии данных и отчёта из практики
  «Отчёт по рекламным каналам» модуля 8. Если вы её прошли, берите свои файлы из `../launch-kit/inputs/` и
  `../launch-kit/outputs/`: числа должны совпасть.
- `design.md` и `design/` — пример стиля ролика: цвета, шрифты, размеры, сетка, движение и список того, чего
  в ролике нет, и кадры ролика в этом стиле.
- `checks/check_reel.py` — автопроверка ролика.

## Где живёт проект

Ролик — отдельный проект Remotion рядом с `launch-kit`, например `reel-01`. Его создаёт плагин Remotion для
Claude Code, а Node.js нужен версии 24 или новее. В проект из набора ничего копировать не нужно: Claude
читает данные прямо из `../launch-kit/` или `../claude-code-kit/reels/inputs/`.

Проверка ждёт такие файлы:

```text
reel-01/
├── storyboard.md            раскадровка: время, кадр, субтитр
├── package.json
└── out/
    ├── reel-01.mp4          версия для Reels и TikTok
    ├── reel-01-shorts.mp4   версия для YouTube Shorts
    ├── cover.png            обложка
    └── Reel/reel-01-shorts.srt
```

Файл субтитров Remotion кладёт в папку с именем композиции внутри `out/`; проверка ищет его по всей `out/`.

## Проверка

Из папки проекта после рендера:

```bash
python3 ../claude-code-kit/reels/checks/check_reel.py
```

Проверка только читает файлы: размер кадра, частоту и длительность берёт из самого MP4, ничего не
запускает и не ходит в сеть.
