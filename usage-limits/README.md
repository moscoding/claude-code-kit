# usage-limits

Файл к задаче урока «Модель, усилие и расход» (модуль 1 «Введение в Claude Code»).

- `usage.txt` — вывод команды `/usage` из терминала у коллеги на тарифе Max: текстовая форма строк о лимитах подписки.

Файл открывают в браузере и читают, копировать его никуда не нужно. Числа учебные.
