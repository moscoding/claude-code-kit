# План дашборда «Пульт запуска»

Страница: `outputs/dashboard.html`, публикуется артефактом Claude Code и открыта людям организации.

## Блоки

1. **Открытые задачи launch-kit** — коннектор GitHub из claude.ai, вызов при открытии страницы.
2. **Задачи дизайна** — коннектор Linear из claude.ai, вызов при открытии страницы.
3. **Решения из #launch** — коннектор Slack из claude.ai, вызов при открытии страницы.
4. **Ответы из вики** — сервер `wiki` из `.mcp.json` проекта, вызов при открытии страницы.
5. **Расходы по каналам** — `outputs/channel-summary.csv`, данные вписаны в страницу при публикации.

## Коннекторы в аккаунте claude.ai Никиты

- GitHub — подключён.
- Slack — подключён.
- Linear — не подключён.
- Google Drive — подключён.
