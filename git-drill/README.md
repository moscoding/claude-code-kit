# git-drill

Учебный репозиторий для практики «Ветка, конфликт и откат» (модуль 11).

Собрать, из папки launch-kit:

    python3 ../claude-code-kit/git-drill/setup.py

Проверить, из папки git-drill-work:

    python3 ../claude-code-kit/git-drill/checks/check_git_drill.py

Начать заново (старая копия переименуется, не удалится):

    python3 ../claude-code-kit/git-drill/setup.py --fresh
