# Дайджест канала #launch и документов запуска

Здесь две выгрузки за конец сентября — начало октября 2026 года:

- `slack-export/` — экспорт Slack: `users.json`, `channels.json` и папка канала `launch/` с файлом на каждый день;
- `docs/` — документы папки «Запуск лендинга» из Google Drive, выгруженные в Markdown.

## Правила команды

1. Неделя — с понедельника по воскресенье. День сообщения — дата в имени файла дня.
2. Решение — сообщение человека с реакцией `white_check_mark` (✅). Реакция `heavy_check_mark` (✔️) и другие реакции решением не делают.
3. Сообщения ботов (`"subtype": "bot_message"`) — не решения, даже с ✅.
4. Служебные записи с `"subtype"`, например `message_changed`, — не отдельные сообщения. Текст правленого сообщения — поле `text` самого сообщения.
5. Упоминание `<@U…>` заменяется на `real_name` человека из `users.json`. В дайджесте нет идентификаторов вида `U01…`.
6. Документ входит в неделю по полю `date` в шапке файла, а не по имени файла. `README.md` — не документ.

## Формат дайджеста

```text
# Дайджест #launch: 2026-09-28 — 2026-10-04

## Решения

- 2026-09-28 · Имя: текст сообщения дословно

## Документы

- 2026-09-29 · Название документа

Итого решений: N
```

Решения и документы — по дате, от ранних к поздним. Последняя строка файла — `Итого решений: N`.
