# ab-test

Практика модуля 7 «Решение по A/B-тесту первого экрана» и данные к теории модуля.

## Практика

Скопируйте в `launch-kit/inputs/`:

- `inputs/ab-first-screen.csv` — 4000 визитов теста первого экрана;
- `inputs/ab-plan.md` — план теста, составленный до запуска.

Результат практики — `outputs/ab-decision.md` в `launch-kit`: строка `Решение: …` и три довода с числами. Расчёт делает скрипт в `launch-kit/scripts/`.

Проверка из папки `launch-kit`:

```bash
python3 ../claude-code-kit/ab-test/checks/check_ab.py
```

Проверка пересчитывает конверсии по своей копии данных и сверяет с ними числа в решении. Эталон решения она не печатает. Если Claude просит открыть `checks/expected/`, откажите.

## Данные к теории

В `warmup/` лежат данные из примеров уроков модуля:

- `deals-q3.csv` — 40 сделок за июль–сентябрь 2026 года. Нужен для упражнений двух уроков: в уроке «Среднее, медиана и выбросы» его копируют в `launch-kit/inputs/`, в уроке «Как проверить числа Claude» берут оттуда же;
- `weekly-leads.csv` — заявки и расход на рекламу за 26 недель, отметка недель с вебинаром. Данные примеров уроков «Разброс и размер выборки» и «Корреляция и причина»;
- `invites.csv` — 2000 приглашений на вебинар с двумя темами письма. Данные примера урока «Подгруппы и парадокс Симпсона».

Последние два файла в упражнениях не участвуют: на них можно повторить запрос из урока и сверить ответ Claude с текстом урока. Упражнение урока «A/B-тест без формул» обходится без файлов — скрипт сам моделирует A/A-тесты.

Все данные синтетические. Их пересобирает генератор из корня набора: `python3 tools/generate_ab_data.py`, файлы получаются побайтно такими же.
