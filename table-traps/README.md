# table-traps

Фрагменты к разбору «Ловушки таблиц» курса «Основы Claude Code».
Откройте файлы в Google Sheets и проверьте свои ответы формулами из урока.
`01-dates.csv` импортируйте в таблицу с локалью «США», `02-separators.csv` —
в две таблицы, с русской и американской локалью. В книге `traps.xlsx` — листы
с третьего по шестой фрагмент.

Ответов здесь нет: они в уроке, в блоке «Сверить с разбором». Пересборка из
корня набора: `python3 tools/build_table_traps.py table-traps`.
