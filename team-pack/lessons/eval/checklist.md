# Чеклист апдейта для клиента

Апдейт принимают, если на все вопросы ответ «да».

1. Есть три раздела: «Готово», «В работе», «Что ждём»?
2. Апдейт не длиннее 120 слов?
3. У каждого пункта указаны файл и строка источника?
4. В тексте нет имён участников команды?
5. В тексте нет финального юридического текста?
