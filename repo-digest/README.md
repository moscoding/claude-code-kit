# repo-digest

Практика модуля 15 «Ежедневный дайджест репозитория» и примеры к урокам «Запуск без диалога: claude -p»
и «GitHub Actions и @claude».

Собрать учебный репозиторий, из папки launch-kit:

    python3 ../claude-code-kit/repo-digest/setup.py

Проверить, из папки digest-work:

    python3 ../claude-code-kit/repo-digest/checks/check_digest.py

Начать заново (старая копия переименуется, не удалится):

    python3 ../claude-code-kit/repo-digest/setup.py --fresh

samples/ — файлы для уроков, в практике не используются.
