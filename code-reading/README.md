# code-reading

Разбор модуля 10 «Четыре фрагмента кода».

В `fragments/` четыре коротких скрипта-«помощника» к недельному отчёту:

- `send_summary.py` — фрагмент A;
- `cleanup.py` — фрагмент B;
- `report_xlsx.py` — фрагмент C;
- `notify_team.py` — фрагмент D.

Фрагменты только читают, в `launch-kit` их не копируют. Вторая строка каждого файла — `raise SystemExit(...)`: если файл всё же запустить, он остановится до первой опасной строки и напечатает «Учебный фрагмент для чтения. Не запускайте его.». Адреса в файлах — в зарезервированной зоне `.example`, токен помечен `EXAMPLE`, пакета с таким именем нет.

Главный риск каждого фрагмента запишите в `launch-kit/work/code-reading.md`, по строке на фрагмент: буква, двоеточие и одно-два слова из списка «сеть», «удаление», «установка», «секрет», например `A: сеть`.

Проверка из папки `launch-kit`:

```bash
python3 ../claude-code-kit/code-reading/checks/check_reading.py
```

Проверка отмечает каждую строку, но правильных ответов не печатает. Эталон лежит в `checks/expected/`: открывайте разбор в уроке после проверки, а не файл эталона.
