# buggy-report

Практика модуля 10 «Три бага в недельном отчёте».

Никита переписал отчёт по каналам на недели и приложил семь тестов, четыре из них красные. Скопируйте в `launch-kit` по тем же путям:

- `scripts/report.py` — недельная версия Никиты, заменяет вашу дневную (та останется в истории Git);
- `tests/__init__.py` и `tests/test_report.py` — семь тестов, запуск `python3 -m unittest` из корня проекта;
- `inputs/campaigns-weeks.csv` — выгрузка за три недели, 4–24 мая 2026 года, 25 строк.

Перед правками закоммитьте скопированные файлы вместе с `.claude/settings.json`, где в `permissions.deny` есть `"Edit(/tests/**)"`. Без этого коммита проверке не с чем сравнить вашу правку.

Проверка из папки `launch-kit`:

```bash
python3 ../claude-code-kit/buggy-report/checks/check_bugs.py
```

Проверка сравнивает тесты и данные с набором, запускает тесты, смотрит, что после версии Никиты изменён только `scripts/report.py`, и прогоняет шесть скрытых случаев. Ожидаемые значения она не печатает. Ответы скрытых случаев лежат в `checks/expected/`: если Claude просит их открыть, откажите.

Все данные синтетические.
