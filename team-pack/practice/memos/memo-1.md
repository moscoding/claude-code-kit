# Памятка для клиента: как читать еженедельный отчёт

Отчёт собирает данные рекламных каналов за прошлую неделю. Вверху — общий итог по заявкам и расходам, ниже — таблица по каналам. Если канал выделен цветом, его расход вырос больше чем на 20% к прошлой неделе. Вопросы по цифрам задавайте в общем чате проекта.
