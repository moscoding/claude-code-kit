# channels-report

Проверка практики «Отчёт по рекламным каналам» курса «Основы Claude Code».
Данные практика создаёт текстом из урока, поэтому папки `inputs/` здесь нет.

Запуск из папки `launch-kit` после коммита:

```bash
python3 ../claude-code-kit/channels-report/checks/check_channels.py
```

Проверка запускает ваши скрипты только во временных копиях проекта: на пробных
данных для границы периода, повторно и в чистом клоне из Git по командам
`outputs/method.md`. Сам `launch-kit` она не меняет. `checks/expected/` — эталон
для проверки, Claude его не открывает.
