# plugin-cost

Файл к задаче урока «Плагины» (модуль 13 «Скилы, хуки и автономность»).

- `details.txt` — вывод команды терминала `claude plugin details launch-tools`: из чего состоит учебный плагин и сколько токенов он добавляет к сессии.

Плагин `launch-tools` и маркетплейс `moscoding-launch` учебные. Файл открывают в браузере и читают.
