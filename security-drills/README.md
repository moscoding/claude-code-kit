# security-drills

Материалы к задачам в теории модуля 16 «Безопасность». Автопроверки здесь нет: ответы вводят в уроке.

- `leaked-key/setup.py` — собирает рядом с набором учебный репозиторий `leaked-key-drill`, в истории которого
  остался ключ (урок «Секреты и мок-данные»). Запуск из `launch-kit`:
  `python3 ../claude-code-kit/security-drills/leaked-key/setup.py`.
- `weekly-helper/` — учебный плагин для разбора до установки (урок «Доверие к расширениям»).
  Его не устанавливают и не запускают: папку только читают.

Ключ в `leaked-key` учебный и нигде не действует. Адреса в `weekly-helper` ведут на домены `.example`
и `.example.com`, которые никуда не ведут.
