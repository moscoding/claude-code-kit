# mod-review

Файл к задаче урока «Моды» (модуль 13 «Скилы, хуки и автономность»).

- `validate.txt` — вывод команды терминала `claude plugin validate ./context-chart` (Claude Code 2.1.304) для учебного мода
  `context-chart`. Мод обещает панель с заполненностью контекста после каждого хода.

Код мода в набор не входит: что мод получает и что вызывает, видно по строкам `hooks:` и `calls:`. Мод учебный. Файл
открывают в браузере и читают.
